PIVORA STREET — VERCEL + PIX
===========================

CONFIGURADO NESTA VERSÃO
- WhatsApp da loja: +55 27 98876-0183
- QR Code Pix fornecido pelo proprietário
- Pix Copia e Cola fornecido pelo proprietário
- Pedido encaminhado ao WhatsApp para combinar entrega e confirmar o pagamento

COMO PUBLICAR
1. Faça upload/importação dos arquivos deste ZIP na Vercel.
2. Mantenha index.html, vercel.json e pix-qrcode.png juntos na raiz do projeto.
3. Publique o site.
4. Teste em celular e computador: abra um produto, adicione ao carrinho e envie um pedido de teste pelo WhatsApp.

COMO FUNCIONA O PEDIDO
1. O cliente escolhe os produtos e preenche os dados.
2. O site abre uma mensagem de pedido no WhatsApp +55 27 98876-0183.
3. O cliente pode usar o QR Code Pix ou o botão Copiar código Pix exibidos no checkout.
4. O cliente deve conferir o nome do destinatário e o valor no aplicativo bancário antes de confirmar.
5. A loja deve confirmar o crédito recebido no aplicativo bancário antes de enviar o produto.
6. Frete e total final devem ser combinados com o cliente.

IMPORTANTE
- Este site não verifica automaticamente se um Pix foi pago.
- O código Pix fornecido não inclui um valor fixo aparente; confirme o valor final no aplicativo antes de pagar.
- O nome do favorecido no QR/código informado é VINICIOS BATISTA RAASCH. Confirme que esse é o destinatário correto antes de publicar.
- Não há cálculo automático de frete, backend de pedidos ou controle de estoque.
- Se quiser usar link de pagamento PicPay em vez deste Pix, será necessário criar cada cobrança no app (se o recurso estiver disponível) e enviar o link manualmente ao cliente.
