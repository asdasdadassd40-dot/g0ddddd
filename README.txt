PIVORASTREET — pacote para Vercel

COMO PUBLICAR:
1. Extraia este ZIP no computador.
2. Entre em https://vercel.com e faça login.
3. No painel, escolha Add New > Project e importe um repositório Git,
   ou use a CLI da Vercel a partir desta pasta.
4. Se usar a CLI: instale Node.js, abra o terminal nesta pasta e execute:
   npx vercel
   Siga as perguntas e confirme o deploy. Para publicar em produção:
   npx vercel --prod

O arquivo index.html é a página inicial e vercel.json contém configuração
básica para hospedagem estática.

IMPORTANTE:
- Este pacote publica o site visual. O checkout ainda é demonstrativo.
- Pix, cartão de crédito e débito não estão conectados a um provedor real.
- Antes de vender, configure gateway de pagamento, frete, estoque, política de
  privacidade, trocas/devoluções e dados de contato.
- O arquivo HTML usa imagens embutidas; não precisa de pasta separada de imagens.
